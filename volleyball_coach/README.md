# 排球临场指挥

单教练在场边用的轮次、固定换人和赛后复盘。第一版不识别录像，也不把没确认的内容写成事实。

## 运行

```bash
python -m volleyball_coach
```

浏览器打开 `http://127.0.0.1:5055`。数据写在 `volleyball_coach/data/coach.db`。页面可以断网使用。

## 球队

男排按已确认的本地赛制导入：禁止后排进攻、无自由人、固定一对一、无限往返。D 换 Andy A 是已确认配对。Harvey 换 Michael 只是候选，开场不勾选就不能上场。

另外的小队用首页「新建球队」。默认是空白规则，不会复制男排名单。选「只套用规则开关」也只复制那几个开关。每场比赛在开场时留下规则快照，之后改规则不影响这场。

## 场边

预案模式可以不点比分，轮次手动选，这时会标明统计没有实时更新。轻记录每分点一次谁得分：我方接发得分才轮转，连续发球得分不轮转，换人也不轮转。

漏记用校正。校正只建立你确认的当前状态，不反推中间的分。撤销和关掉页面后再打开，都从事件记录重放。

## 赛后

先回答三个问题：哪一轮接发最难，发球目标有没有执行到，替补上场后在可比条件下发生了什么。未知不记成 0。关键片段不能算整场得分率。换人前后如果对手、发球队员或一传质量对不齐，报告只并列，不把胜负差写成提升。

JSON 在每场报告页的「导出 JSON」。缺的字段是 `null`，不是 0。
