\enzh{每位学生只发放一套试卷。请尽量在当场时限内一次完成（约两小时，以该套试卷倒计时为准，115--150 分钟）。如遇断网、误关网页等特殊情况，学生可凭事先抄下的恢复码返回续考；恢复码自开考起仅有效 \textbf{24 小时}，逾期未提交则系统删除该场试卷，Advisor 后台无法查看。开错试卷同样占用此时限。}{Assign one test only. \end{tcolorbox}

\section{考前须知 / Pre-exam notice}

\begin{itemize}
  \item \enzh{\textbf{选择该 Advisor 姓名}：Mia Hu / Jimmy Zheng / Other（填写全名）。选错则本场试卷不会出现在该 Advisor 名单中。}{\textbf{Select that advisor:} Mia Hu / Jimmy Zheng / Other (full name). If the wrong name is chosen, the test will not appear in that advisor's roster.}
  \item \enzh{\textbf{请尽量当场完成。}各套限时约两小时（以屏幕倒计时为准）。倒计时不会因离开网页而暂停或重置。}{\textbf{Finish in one sitting.} Each test is about two hours on the on-screen clock. Leaving the page does not pause or reset the countdown.}
  \item \enzh{\textbf{当场抄下恢复码}（\texttt{XXXX-XXXX-XXXX-XXXX}），并另行保存。仅在断网、误关网页等特殊情况下用于续考。恢复码自开考起有效 \textbf{24 小时}，逾期未提交则删除，Advisor 无法查看。}{\textbf{Copy the recovery code} immediately and keep it outside the browser. Use it only if the student must leave. It is valid for \textbf{24 hours} from the start. After that, unsubmitted work is deleted and the advisor cannot see it.}
  \item \enzh{\textbf{Enhanced}：下载或打印空白 PDF，纸上作答，最后上传 \textbf{一份} PDF，再 Final Submit。}{\textbf{Enhanced:} download or print the blank PDF, work on paper, upload \textbf{one} PDF, then Final Submit.}
  \item \enzh{请使用电脑或平板。}{A laptop or tablet is required.}
\end{itemize}
